# 连续画面脚本示例

用户提供的格式与行文示例。学习其「总规格 → 镜头标题 → 时间段 → 连续画面描述」结构，以及动作、运镜、材质与衔接融入正文的写法。以下产品、原料、时长、画幅、镜头数和具体表现只属于本项目，不作为其他项目的固定要求或已核实产品声明。

15秒｜16:9横版｜7个镜头

镜头1｜掠过桶沿，看见抹茶大颗粒
00:00–00:01.5

已开盖的抹茶大桶占据画面中央，绿色桶盖位于后侧。画面从包装正面的近景开始，镜头沿桶身斜向上抬，越过桶沿，完整露出平整的抹茶料体。

嵌在料体中的布朗尼方块形成清楚的前后层次。镜头贴近最前方的一块，布朗尼切面迅速放大，接入原料空间。

镜头2｜布朗尼翻身，抹茶粉擦过切面
00:01.5–00:04

几块布朗尼在绿色空间中前后错落，最近的一块略虚，中央主块清晰。

中央布朗尼缓缓翻过一个角度，松软的切面转向镜头。一股细薄的抹茶粉从侧后方掠来，擦过方块棱角，在切面上留下细腻粉层。

镜头从两块布朗尼之间向前穿行，近处块体快速掠过，远处块体移动较慢，形成明显空间感。

最后一块布朗尼从镜头前横向掠过，短暂遮满画面，带出下一款产品。

镜头3｜巧克力产品旋正
00:04–00:05.5

前景遮挡离开，露出已开盖的巧克力大桶。背景是温暖的金棕色，产品以轻微侧转的姿态出现，随后小幅转正。

镜头保持略俯视角，包装和桶内料体同时可见。转正过程中，一道柔光扫过桶口，让黑色曲奇断面从巧克力色料体中显露出来。

在曲奇断面最清楚的位置切入微距，保持它在画面中的方向一致。

镜头4｜巧克力液幕挂过曲奇
00:05.5–00:08

极近景，两块不规则可可曲奇前后错开，断面粗粝、边缘清楚。

一道浓稠巧克力液从斜上方落下，先搭上前方曲奇的棱角，再沿着侧面缓缓挂流，在两块曲奇之间拉出短短的弧形液幕。曲奇仍有一部分裸露，能同时看到粗糙断面与顺滑巧克力。

镜头贴着液幕侧向移动，高光沿弧面滑过。液幕下缘落下时，直接切到下一镜同方向的蓝色桶盖边缘。

镜头5｜越过蓝色桶盖，露出香草牛乳
00:08–00:09.5

蓝色桶盖边缘位于前景，镜头向下掠过，已开盖的香草牛乳大桶完整露出。

乳白色冰淇淋铺满桶口，不规则黑曲奇半嵌在料体中。镜头落到略俯的侧前方，产品正面与开口同时进入构图。

焦点从前方蓝色桶沿转到一块黑曲奇，切入它的原料特写。

镜头6｜曲奇裂开，乳白液体从间隙穿过
00:09.5–00:12

一块可可曲奇占据画面中心，背后是明亮、柔和的乳白空间。

曲奇沿不规则纹路裂成几块，块体缓缓向左右错开，少量细屑落下。镜头贴近裂口，清楚看见新露出的粗粝断面。

一道乳白色液体从块体后方穿过间隙，向前舒展开来，形成柔软弧面。黑色曲奇停留在前后不同位置，乳白液体在中间流过，画面由紧密变得舒展。

弧形液面掠过下半画面时，切入三款产品集合。

镜头7｜拉开空间，三款大桶集结
00:12–00:15

切入较近的三款开盖产品画面，抹茶位于中央稍前，巧克力与香草牛乳分列两侧，各自桶盖位于后侧。

镜头从桶口高度向后拉开，同时略微抬高，逐渐完整呈现三款包装、三种料体和其中的大颗粒。

产品前方只保留少量对应的布朗尼与曲奇，形成从前景原料到后方产品的层次。镜头减速，稳定停在三款产品完整、饱满的集合构图上。
